# معماری فنی «کتابچه قانون»

## نمای کلی

```
                       ┌────────────────────────────────────────────┐
   منابع خام            │ scripts/lib/fa.mjs + parse.mjs             │
   data/sources/**  ──▶ │ scripts/build-data.mjs                     │──▶ public/data/**
                       └────────────────────────────────────────────┘
                                                │
                          (فایل‌های ایستا + Service Worker + IndexedDB)
                                                ▼
   ┌───────────────────────────────────────────────────────────────────────┐
   │  Next.js App Router (RTL, fa)                                          │
   │   DataBootstrap → همگام‌سازی دلتا → Dexie (laws, articles, …)          │
   │   AppShell (TopBar جست‌وجو + BottomNav ۵ زبانه + نشانگر آفلاین)        │
   │   صفحات: خانه، قوانین، ماده، جست‌وجو، نشان‌ها، تنظیمات، پوشش…          │
   │   Worker جست‌وجو: MiniSearch + مسیر سریع شماره ماده                    │
   └───────────────────────────────────────────────────────────────────────┘
```

## لایه‌ها

### ۱) خط تولید داده (`scripts/`)

- `lib/fa.mjs` — نرمال‌سازی فارسی، ارقام، ایست‌واژه‌ها، تشخیص وضعیت/اصلاحیه، تجزیه پرس‌وجو.
- `lib/parse.mjs` — تجزیه‌گر سه‌گانه: متن قانون (`❯`/`ماده`)، JSON ساخت‌یافته (HUB)، YAML قانون اساسی؛
  به‌علاوه `normalizeArticle` که شکل یکسان ماده‌ها را می‌سازد.
- `build-data.mjs` — ساخت `catalog.json` و فایل‌های قانون + هش محتوا + نسخه‌بندی + آمار شکاف.
  فقط اسنادی که متن ماده‌به‌ماده دارند وارد داده‌های نهایی می‌شوند؛ مادهٔ بدون متن هم حذف می‌شود.
- `validate-data.mjs` — اعتبارسنجی ساختاری/نرمال‌سازی + ۲۵ آزمون صحت متنی + بررسیِ نبودِ
  ارجاع به مخازن بیرونی در دادهٔ منتشرشده.
- `verify-registry.mjs` — تطبیق «فهرست مرجع ورودی» با کاتالوگ ساخته‌شده (گزارش موجود/ناموجود).
- `gen-icons.mjs` — تولید آیکون‌های PWA با Sharp.

**نسخه‌بندی:** نسخه = `1.0.0+<hash>`؛ هش هر قانون جداگانه محاسبه می‌شود. برنامه با خواندن
`version.json` فقط قوانینی را که هش‌شان تغییر کرده دوباره می‌گیرد.

### ۲) لایه داده سمت مرورگر (`src/lib/`)

| فایل | نقش |
| --- | --- |
| `types.ts` | تایپ‌های مشترک (ماده، قانون، کاتالوگ، پیشرفت همگام‌سازی) |
| `server/data-version.ts` | تشخیص نسخهٔ داده از روی `version.json` برای صفحات ایستا |
| `db.ts` | Dexie: جداول `laws, articles, bookmarks, notes, history, meta` — همه‌چیز محلی |
| `sync.ts` | دریافت اشاره‌گر نسخه، مقایسه هش‌ها، دریافت دلتا با پیشرفت، جای‌گذاری تراکنشی + شمارش محلی |
| `search-client.ts` | مدیریت Worker جست‌وجو، ایندکس‌گذاری، فیلترها و مسیر سریع شماره ماده |
| `use-search.ts` | هوک‌های React: آماده‌سازی موتور (با کلید `dataVersion`) و اجرای جست‌وجو با debounce |
| `fa.ts` | دوقلوی مرورگر `fa.mjs` (نرمال‌سازی، ارقام، تجزیه پرس‌وجو، برجسته‌سازی) |
| `format.ts` | قالب‌بندی عدد فارسی، تاریخ جلالی، فاصله زمانی، حجم |
| `share.ts` | اشتراک‌گذاری بومی (`navigator.share`) با بازگشت به کلیپ‌بورد |
| `calc/` | منطق محاسبه‌گر ارث (مواد ۸۶۲–۹۴۹) و دیه (مواد ۵۶۳ به بعد) |
| `store.ts` | وضعیت سراسری (Zustand): کاتالوگ، نسخه داده، تنظیمات مطالعه، پیشرفت |

### ۳) رابط کاربری (`src/app`, `src/components`)

- `layout.tsx` — RTL/fa، فونت وزیرمتن (self-host با `next/font/local`)، متادیتا و manifest،
  زنجیره پروایدرها: `ThemeProvider → DataBootstrap → AppShell`.
- `DataBootstrap` — اسپلش با پیشرفت، بازیابی از کش، تلاش مجدد، نمایش اعتبار حقوقی/توسعه‌دهنده.
- `AppShell` — نوار بالا با جست‌وجوی زنده روی ماده‌ها، ناوبری پایین ۵ زبانه، نشانگر آفلاین،
  بنر نصب، اسکلتون‌ها.
- `bits.tsx` — اجزای مشترک: فهرست تدریجی ماده‌ها، Sheet تنظیمات مطالعه، Sheet فیلترها،
  دکمه‌های عملیات ماده، ویرایشگر یادداشت، نوار آمار.
- `article-card.tsx` — کارت ماده با کشیدن: راست → نشان‌گذاری، چپ → اشتراک، لمس → متن کامل.
- صفحات: `/`، `/laws`، `/laws/[lawId]`، `/article/[articleId]`، `/search`، `/bookmarks`،
  `/settings`، `/coverage`، `/calculator/inheritance`، `/calculator/diyyeh`، `/about`، `/offline`.

### ۴) PWA (`public/sw.js`)

- **پیش‌بارگذاری پوسته**: مسیرهای اصلی در نصب کش می‌شوند.
- **داده‌ها**: `/data/v<version>/…` با راهبرد **cache-first** (تغییرناپذیر)؛ `version.json` با شبکه-اول.
- **دارایی‌ها**: `/_next/static/…`، فونت‌ها و آیکون‌ها با cache-first.
- **ناوبری**: شبکه-اول با پشتیبان کش و صفحهٔ `/offline`.
- **همگام‌سازی پس‌زمینه**: `sync` و `periodicsync` برای بررسی نسخه جدید داده و اطلاع به برنامه.

## کارایی

- بسته اولیه: حدود ۱۹۰–۲۰۰ کیلوبایت JS در هر مسیر (بودجه: <۳۰۰KB).
- فهرست ماده‌ها برای قوانین بزرگ **تدریجی** رندر می‌شود (۱۳۳۵ ماده قانون مدنی ⇒ فقط چند کارت در DOM).
- ایندکس جست‌وجو و جست‌وجو در **Web Worker** اجرا می‌شود؛ رابط کاربری قفل نمی‌شود.
- داده‌ها قطعه‌قطعه (۳۰۰ ماده‌ای) دریافت می‌شوند تا هر درخواست کوچک و قابل‌کش باشد.
- تمام فونت‌ها، آیکون‌ها و داده‌ها **محلی** هستند؛ هیچ درخواست خارجی در زمان اجرا وجود ندارد (شرط آفلاین).

## حریم خصوصی

هیچ سروری برای داده کاربر وجود ندارد: یادداشت‌ها، نشان‌ها، تاریخچه و تنظیمات در IndexedDB
ذخیره می‌شوند و همه‌چیز روی دستگاه می‌ماند.
