# استخراج متن قوانین (Scrapers)

این پوشه ابزارهای «تکمیل داده» را دارد: اسکریپت‌هایی که متن قوانین را از منابع
رسمی می‌خوانند و به قالب داخلی برنامه (همان قالب `corpus`) تبدیل می‌کنند.

> نسخه فعلی برنامه با **مجموعه هسته‌ای بازبینی‌شده** (۴۰ سند / ۶٬۶۱۸ ماده) عرضه
> می‌شود. این اسکریپت‌ها برای وقتی است که می‌خواهید بقیه قوانین (مثلاً قانون
> معادن، اوقاف، برنامه‌های توسعه، مدیریت خدمات کشوری، آرای وحدت رویه و نظریات
> مشورتی) را خودتان اضافه کنید.

## نصب

```bash
python3 -m venv .venv && source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r scripts/scrape/requirements.txt
python -m playwright install chromium                    # فقط برای qavanin.ir
```

## استفاده

```bash
# ۱) سامانه ملی قوانین (qavanin.ir) — نیازمند Playwright
python3 scripts/scrape/scrape_qavanin.py --query "قانون معادن" --dry-run
python3 scripts/scrape/scrape_qavanin.py --query "قانون معادن" --out data/sources/scraped --delay 4

# ۲) مرکز پژوهش‌های مجلس (rc.majlis.ir) — بدون مرورگر
python3 scripts/scrape/scrape_rc_majlis.py --query "قانون اوقاف" --dry-run
python3 scripts/scrape/scrape_rc_majlis.py --url "https://rc.majlis.ir/fa/law/show/135019" --out data/sources/scraped

# ۳) افزودن فایل استخراج‌شده به فهرست داده‌ها
cp data/sources/scraped/*.txt data/sources/lawcorpus/
node scripts/scrape/add_to_catalog.mjs \
  --id mining-law --file mining-law.txt \
  --title "قانون معادن" --short "معادن" \
  --category sayer --hierarchy statute --date "1377/11/23" --checklist mining

# ۴) اعتبارسنجی و ساخت مجدد داده‌ها
npm run data:validate
npm run data:build
```

نکته: نام فایل‌های خروجی خودکار از عنوان ساخته می‌شود؛ اگر می‌خواهید نام دقیقی
داشته باشند از `--slug` استفاده کنید.

## قالب فایل corpus

```
نام قانون
مصوب ۱۳۷۷/۱۱/۲۳

❯ فصل اول — کلیات
ماده ۱
متن ماده ...
تبصره ۱ — متن تبصره ...

ماده ۲
...
```

- شماره ماده‌ها می‌تواند فارسی یا لاتین باشد (در زمان ساخت داده یکسان‌سازی می‌شود).
- سطرهای `❯` سرفصل (کتاب/باب/فصل/مبحث/بخش/گفتار) هستند.
- پیامد این قالب: قابلیت ویرایش دستی، `git diff` خوانا و بازبینی حقوقی ساده.

## نکات حقوقی و فنی

1. **robots.txt را رعایت کنید.** هر دو اسکریپت پیش از هر درخواست بررسی می‌کنند و
   در صورت منع، متوقف می‌شوند. فاصله پیش‌فرض بین درخواست‌ها ۳ ثانیه است؛ برای
   دریافت انبوه آن را کمتر نکنید و ابتدا با پشتیبانی سامانه هماهنگ کنید.
2. **نیاز به بازبینی انسانی.** متن استخراج‌شده خودکار ممکن است خطای OCR یا
   برش‌خوردگی داشته باشد؛ فایل خروجی را با نسخه روزنامه رسمی مقایسه و در صورت
   نیاز دستی اصلاح کنید. برنامه در «گزارش پوشش» و داخل هر ماده منبع داده را
   نشان می‌دهد.
3. **متن قوانین، سند رسمی و فاقد حمایت حقوق مؤلف است**، اما پایگاه‌داده‌های
   ویرایش‌شده ممکن است شرایط استفاده داشته باشند؛ پیش از بازنشر انبوه شرایط
   هر منبع را بررسی کنید.
4. اگر ساختار HTML سایت تغییر کند، سلکتورها را در بالای اسکریپت
   (`CONTENT_SELECTOR_CANDIDATES` و `ARTICLE_BLOCK_CANDIDATES`) به‌روز کنید یا با
   `--dump-html` خروجی خام را ذخیره و بررسی کنید.
