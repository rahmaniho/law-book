## تفاوت‌های عامدانه با مبدأ

1. package-lock مستقل وب با lockfile مشترک npm workspaces جایگزین شد؛ scripts وب همچنان از پوشهٔ خود اجرا می‌شوند. حداقل Node برای تست‌ها ۲۲٫۱۷ است.
2. دو workflow مبدأ وارد مسیر فعال نشدند. `deploy.yml` در ریشه بازتنظیم شد؛ `nextjs.yml` تکراری کنار گذاشته شد. CI جداگانه هیچ deploy ندارد.
3. basePath پیش‌فرض این مخزن `/law-book` است؛ برای مبدأ `/Lawbook` یا دامنهٔ اصلی مقدار محیطی صریح پشتیبانی می‌شود. آدرس‌های share نیز با basePath ساخته می‌شوند.
4. صفحهٔ خواندن مشترک، helper لینک‌ها و پیش‌کش کامل وابستگی‌های پوسته اضافه شدند؛ صفحات legacy حذف نشده‌اند. رابط و دادهٔ خوانندهٔ قبلی دوباره استفاده شده‌اند.
5. مسیر فونت‌ها با hoisting در مونوریپو سازگار شد. فونت خارجی جدیدی اضافه نشده است.
6. منابع `data/` و snapshot اولیهٔ `public/data` بدون تغییر محتوایی وارد شدند. خروجی تازهٔ build برای تست تولید شد، اما به snapshot واردشده تحمیل نشد.

هیچ فایلی در مخزن مبدأ تغییر نکرده است. اگر استقرار قدیمی باید متوقف شود، workflowهای آن باید در همان مخزن و با تصمیم مستقل غیرفعال شوند. انتقال به این مونوریپو آن را خودکار خاموش نمی‌کند.
