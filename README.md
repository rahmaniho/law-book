## گزارش فاز اول

[`docs/PHASE-1-AUDIT.md`](docs/PHASE-1-AUDIT.md) — بررسی کامل سورس واقعی `Lawbook@main` شامل:

- معماری فعلی (Next.js 14 static export + Dexie/IndexedDB + MiniSearch در Web Worker + Service Worker دست‌نویس)
- ۲۳ قابلیت آمادهٔ تأییدشده، ۱۲ مورد ناقص، و فهرست قابلیت‌های موردنیاز برای تجاری‌سازی
- یک **شکاف آفلاین تأییدشده** با اجرای واقعی منطق Service Worker
- معماری تجاری پیشنهادی، مدل داده، برآورد زمان و هزینهٔ زیرساخت
- ریسک‌های امنیتی و فنی به‌تفکیک شدت
- چهار تصمیم تجاری که پیش از شروع فاز دوم لازم است

### شواهد اجرایی گزارش

```
npm ci          → ۴۸۳ بسته، بدون خطا
tsc --noEmit    → بدون خطا
npm test        → ۶۸ آزمون | ۶۷ موفق | ۰ ناموفق | ۱ skip
npm run build   → موفق | ۷٬۳۳۸ صفحهٔ ایستا | خروجی ۲۰۶ مگابایت
npm audit       → ۱۰ آسیب‌پذیری (۱ بحرانی، ۶ بالا، ۳ متوسط)
اسکن اسرار      → تمیز؛ هیچ کلید یا رمزی در مخزن نیست
```

## اصول کاری این پروژه

۱. **هیچ قابلیت موجودی حذف یا بازنویسی نمی‌شود** — همه‌چیز افزودنی است.
۲. تأیید پرداخت و صدور مجوز **فقط سمت سرور**؛ هرگز بر پایهٔ مقدار ذخیره‌شده در مرورگر.
۳. مجوز پایه **مادام‌العمر** است؛ انقضای سشن یا نخریدن به‌روزرسانی آن را باطل نمی‌کند.
۴. هیچ کلید، رمز یا اطلاعات درگاه در کد فرانت‌اند یا مخزن عمومی قرار نمی‌گیرد.
۵. قیمت‌ها از پنل مدیریت تنظیم می‌شوند و در لحظهٔ ایجاد سفارش snapshot می‌گیرند.
۶. قابلیتی «تمام‌شده» اعلام نمی‌شود مگر آنکه واقعاً پیاده‌سازی و آزمایش شده باشد.
